Selected Publications

  1. Efficiency HW-Router: Hardware-Aware Routing for Scalable Multi-LLM Serving

    Ahasan Kabir, Jiaqi Xue, Mengxin Zheng, Qian Lou

    DAC 2026 · 63rd ACM/IEEE Design Automation Conference PDF

    Problem: existing routers choose among LLMs using static model characteristics, missing the performance swings caused by hardware type, load, and contention.
    Solution: bring real-time hardware signals — queue length, cache usage, recent latency — into model selection for accurate latency prediction and SLO-aware routing.
    Result: 3.4–3.9× lower end-to-end latency and 46–48 pp higher SLO attainment than state-of-the-art routers, with ~200 µs routing overhead.

  2. Agents InfraMind: Infrastructure-Aware Multi-Agent Orchestration

    Ahasan Kabir, Jiaqi Xue, Mengxin Zheng, Qian Lou

    arXiv 2026 · preprint arXiv

    Problem: multi-agent LLM systems plan and route from task and model features alone, ignoring infrastructure state — preferred models build deep queues while equally capable ones sit idle.
    Solution: make the full stack infrastructure-aware — a planner that adapts workflow complexity to load, an executor that routes by live queue and cache signals, and a deadline-driven scheduler — trained end-to-end with reinforcement learning.
    Result: up to +7.6 pp higher accuracy with 7× lower latency, sustaining 99.9% SLO compliance under load where every baseline drops below 50%.
